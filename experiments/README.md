# experiments — سجل التجارب

هذا المجلد هو محاولة صادقة لتوثيق ما يمكن إثباته من التجارب. **لا يوجد git history**، ولا سجل commits، ولا تواريخ موثقة لكل محاولة. لذلك:

- `experiments_index.csv` = **118 صف نتيجة** مستخرجة من الملفات الحالية.
- بعض الصفوف baselines أو benchmarks، وليست أفكارًا مستقلة.
- الأفكار القديمة التي لم تُحفظ نتائجها **غير متوفرة**؛ لا يمكن اختراعها.
- `FAILED_IDEAS.md` يشرح الأفكار المرفوضة.
- `PERIOD_SPLIT.md` يشرح حدود الـholdout.

## الملفات

| الملف | المحتوى |
|---|---|
| `experiments_index.csv` | 118 صفًا: group, variant, parameter, value, final, CAGR, max DD, Sharpe, trades, nights, note |
| `EXPERIMENT_LOG.md` | ملخص كل مجموعة، الأرقام، ومسار الدليل |
| `FAILED_IDEAS.md` | الأفكار المرفوضة وأسبابها |
| `PERIOD_SPLIT.md` | ما استُخدم للتصميم، وما لا يصلح كـholdout |
| `CHANGELOG.md` | التغييرات في الحزمة والأرقام |

## العدد

**118 صف نتيجة** + **2,000 مسار Placebo** + **2,000 إعادة Bootstrap** + **25 فحصًا عينيًا** + **16 اختبارًا آليًا**.

هذا لا يعني 118 فكرة فريدة. العدد الحقيقي للأفكار الفريدة أقل، وبعض الأفكار القديمة غير محفوظة. راجع `04_BACKTEST_EXPERIMENTS.md`.
